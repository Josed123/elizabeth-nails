# Elizabeth Nails

A bilingual, mobile-friendly website and web application
for the Elizabeth Nails business.

## Project Goals

- Showcase nail services and pricing.
- Display a photo gallery.
- Allow customers to request appointments by email.
- Connect customers to Instagram and Google Maps.
- Display promotions and business updates.
- Support English and Spanish.

## Technologies

- HTML
- CSS
- JavaScript
- Git and GitHub

## Development Status

Project setup in progress.

## Future Plans

- Responsive website design.
- Language switching.
- Progressive Web App (PWA) capabilities.
